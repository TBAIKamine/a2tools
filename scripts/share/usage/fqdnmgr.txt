Usage: fqdnmgr <subcommand> [options]

All arguments are named flags. Positional arguments are not accepted; every
subcommand takes -d/--domain and/or -r/--registrar as appropriate.

Subcommands:
  check                Check domain status (free/owned/taken)
                        Required: -d FQDN
                        Optional: -r REGISTRAR

  purchase             Purchase a domain
                        Required: -d FQDN -r REGISTRAR

  list                 List domains.
                        No options: all local domains (machine parsable).
                        With -r REGISTRAR: -m local|remote is required.

  certify              Set up DNS challenge for SSL certificate (certbot hook)
                        Required: -r REGISTRAR

  cleanup              Clean up DNS challenge records (certbot hook)
                        Required: -r REGISTRAR

  setInitDNSRecords    Set initial DNS records (A @, A *, MX @)
                        At least one of -d or -r is required.
                        -d FQDN  domain(s) to process; may be repeated, or a
                                 space-separated list
                        -r REGISTRAR  registrar; required when -d is omitted
                        -o        override mode - delete all existing DNS
                                 records and set only the 3 initial ones
                        --sync    wait for DNS propagation before returning
                        -t, --timeout SECONDS  max propagation wait
                                 (default: 600)
                        -v        verbose output; prints a status report at end

  checkInitDns         Check whether initial DNS records have propagated
                        Required: -d FQDN

Options (any subcommand):
  -v, --verbose        Verbose output.
  -h, --help           Show this help.
